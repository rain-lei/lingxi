# LingXi TF font sources

All source fonts are under SIL OFL 1.1. Source outlines remain unchanged;
native bitmaps and web subsets use independent LingXi family names.

TF raster: 20 px / 26 px line box / 2-bit antialiasing / 7029 code points.
All 6763 GB2312 Han characters are verified in every source cmap.
Rare punctuation absent in a style uses the Noto Sans source glyph, recorded below.
