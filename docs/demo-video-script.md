# 灵犀挂件初赛演示视频脚本（精简版）

建议成片：**约 3 分钟**。使用新的无痕窗口录制，关闭通知与无关标签，不展示 API Key、终端或个人信息。

## 0:00–0:20｜开场

画面：`/demo` 首页和挂件视觉。

旁白：

> 灵犀是一款面向校园短任务的随身 AI 挂件。它通过按住说话、OLED 屏显、RGB 灯效和语音反馈完成低打扰交互，网页端作为任务、记忆和设备的统一控制台。

## 0:20–0:55｜一句话生成任务

操作：点击“用示例任务开始”，等待任务卡生成，展示“下周三 18:30”“提前一小时提醒”，点击“确认任务”。

旁白：

> 用户只需说出现场信息，灵犀会识别时间、地点和下一步，把它写成服务器保存的任务。确认后，挂件可以在合适时间通过屏显、灯效和语音提示用户。

画面证据：任务 ID、提醒时间、已确认状态。

## 0:55–1:40｜反馈记忆

操作：进入 `/console`，输入：

```text
下周五18:30图书馆有校园讲座，请整理成任务卡。
```

选择“需要调整”，填写：

```text
以后校园活动都提前一小时提醒。
```

再输入：

```text
下周三18:30主楼302有校园讲座，请整理成任务卡。
```

旁白：

> 灵犀会把用户反馈保存为可检索规则。第二个相似任务没有重复写提前时间，系统仍然命中记忆，并在任务卡中标明“按记忆偏好”。

画面证据：`1 条命中`、token/耗时、按记忆偏好、任务队列。

## 1:40–2:10｜多模态理解

操作：上传一张脱敏校园海报，输入“请概括图片最重要的信息，并整理成任务”。

旁白：

> Step 3.7 Flash 同时支持文字和图片理解。它可以从海报中提取关键信息，并生成后续可管理的任务。

画面证据：图片预览、`step-3.7-flash`、流式结果。

## 2:10–2:35｜挂件与控制台协同

操作：点击“运行设备自检”，展示 OLED、RGB 和状态变化。

旁白：

> 挂件形态包含按键、麦克风、扬声器、OLED 与 RGB 状态反馈；云端负责 Agent 编排和记忆，控制台负责设备配置、任务管理和运行观测。

画面证据：设备自检、倾听—思考—回应状态与 0.4-draft 协议。

## 2:35–2:55｜容错与收尾

操作：开启“断网演练”，提交短任务，展示可恢复状态；回到在线演示页。

旁白：

> 网络异常时，灵犀会明确提示并恢复可操作状态。灵犀已经形成从现场输入、任务执行到反馈记忆的闭环，后续将持续完善真实挂件接入和校园场景验证。

片尾：`灵犀挂件 · 在线演示 · 系统控制台 · GitHub`。

## 录制检查

- 至少出现一次任务 ID、一次记忆命中、一次图片理解和一次设备自检。
- 视频时长控制在 3 分钟左右，导出 1080p MP4。
- 录完运行 `python tools/submission_preflight.py` 检查线上状态。
