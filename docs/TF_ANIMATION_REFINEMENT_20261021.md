# 动画精修 V2：清晰度、动作与校标

## 本次修复

旧版网页预览由板端 128 × 128 RGB565 帧放大而来，细毛和五官在放大前已经丢失；不同完整姿态的透明混合还造成双眼、双鼻与双校标重影。旧蓝蓝和芽芽的尾尖跨过图集单元边界，按固定方格裁切会出现硬截断。

本次从高分辨率原图重新制作网页资源，并为蓝蓝、芽芽生成了完整轮廓源。网页高清帧为 512 × 512 RGBA、20 fps，采用保留透明细节的 APNG；板端独立缩小、编码为兼容原格式的 128 × 128 LXAF。

- 同一动作采用完整真实姿态，头、身体、耳朵、手、尾巴分别连续运动并有不同节奏，不再做整幅姿态溶解。
- 眨眼使用原画的闭眼纹理，上眼睑逐步遮盖眼球；庆祝有预备、落地与收稳。
- 蓝蓝使用独立官方校徽合成，每段高清动画、海报及板端帧均带校标，胸前爪子保留正确前景遮挡。
- 新图集先取完整连通角色，再统一缩放和对齐脚底，保留足够运动余量。

这仍是 3D 风格的二维纹理动画，不是实时 3D 引擎，也没有音素级口型同步。

## 网页体验

动画工坊保留原网址，改为大角色舞台、简短对白、五伙伴选择和六动作卡。可摸摸互动、连播动作、暂停定格，并切换高清观赏与板端实际像素。安装及校验信息折叠显示。

主陪伴页也接入高清动作，跟随真实的待机、录音、思考和播放状态切换。空闲摸摸触发庆祝；对话忙碌时不抢占真实状态。素材未生成、加载失败或无效时回退原静态形象；减少动态、页面隐藏或切换到其他视图时改用静态海报。

校标显示有明确标记：仅当当前高清或板端素材声明已经合成校标时隐藏独立 SVG；未确认时保留官方图层，避免胸口空白。两处页面都检查了该行为。

## 下载及兼容

- **TF 动画包**：卡内 LXAF、板端 GIF 预览、报告及安装说明，适合直接安装。
- **高清离线预览**：可选完整高清素材，体积较大；留在电脑，不需要复制到 TF 卡。
- **板端 LXAF**：供直接复制或板子联网接收。浏览器下载名为 `animations-v1.lxaf`，放进卡根目录的 `lingxi` 文件夹。

新版内容继续使用 LXAF 协议 v1 和卡内文件名 `lingxi/animations-v1.lxaf`。原有 TF 功能固件无需重新编译；未更新 TF 功能固件的板子仍需要先进行那一次应用更新。

发布工具保留首版资源，核验新版文件后，将新 LXAF 同步到固件原有固定下载网址。各包精确大小、帧数、SHA-256 与徽章标记见 `public/animations/v2/manifest.json`、`pack-report.json` 和 `publication-report.json`。

## 验证与实板边界

已检查蓝蓝六张最终海报的校标及轮廓，新增芽芽及其他角色的完整姿态。APNG 独立检查将解码首帧与原始 RGBA 海报逐字节对照，并抽查中间帧透明边缘与尾尖；丢弃存在灰边和残留的 WebP 试验导出。

最终发布还核对 LXAF 结构、body SHA、逐段 CRC、原固件边界兼容、HTTP 下载和网页实际交互。现有固件的播放边界保持：待机、思考自动播放，语音回应只更新小头像并有耗时保护，录音保持静态；安慰和庆祝的实板业务事件仍待接入。

最终产物：TF ZIP 24,011,800 字节，卡内 LXAF 60,457,984 字节，可选高清 ZIP 440,981,720 字节。共 30 段动作、1,230 张板端帧、2,050 张高清帧。已通过本机 HTTP 完整下载核验 TF ZIP 及固件固定资源网址的大小和 SHA-256，高清包与固件包通过 HTTP HEAD 大小检查。报告见 `tmp/tf-v2-http-verification-20261021.json`。

浏览器实测高清原生尺寸 512 × 512，板端预览原生尺寸 128 × 128；说话、摸摸庆祝、暂停定格及主陪伴页庆祝后返回待机均正常。最终截图见 `tmp/tf-v2-final-workshop-20261021.png`，网页中的校标直接来自最终动画帧。

网页高清 20 fps 不代表板端帧率。本轮没有烧录、连接串口、格式化或写入用户 TF 卡，真实卡吞吐、PSRAM 峰值和显示/音频并发仍需后续实板验证。

## 源与复现

新增源和完整内置 imagegen 提示词：`firmware/box_audio_ram/assets/tf-v2/SOURCES.md`。

动画工具：`tools/tf_animation_renderer_v2.c`、`tools/build_tf_animation_v2.py`，依赖主机 GCC、Pillow 与 NumPy。最终文件核验与兼容发布：

```powershell
python tools/publish_tf_animation_v2.py
```

该命令只处理本机资源，不访问 TF 卡和串口。
