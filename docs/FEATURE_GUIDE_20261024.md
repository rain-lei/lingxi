# 灵犀：校园 AI 学习与陪伴伙伴

功能详细介绍 · 2026年10月24日

本文依据当前网页、服务端、固件源码及最近安装验证记录整理。功能已实现不等于已经在今天的现场网络、麦克风和屏幕条件下完成验收；正式展示前仍需做一次真实对话与按键彩排。

## 一、产品是什么

灵犀是一套面向大学生的学习与陪伴原型，由电脑网页、ESP32-S3 BOX 实体设备和本地服务组成。默认伙伴蓝蓝是一只蓝色毛绒袋鼠，胸前带大连理工大学校标，提供具有校园辨识度的陪伴形象。

用户可以向它倾诉、提问、练习中英交流，也可以记待办、设置提醒、开始专注，并查看学习记录。产品希望串起一条实际使用流程：表达当前状态 → 得到回应与建议 → 用户明确保存下一步计划 → 到点提醒与专注 → 留下学习足迹。

## 二、自然对话与情绪陪伴

### 1. 两种输入入口

- 网页：输入文字，或点击麦克风开始录音，再次点击发送；可选择是否播放语音回应。
- 硬件：按住 BOOT 录音，说完松开后发送；当前单段录音最长10秒。回复经板上扬声器播放，也会在板上显示文字。
- 回复播放时可以停止：网页点击“停止播放”；板上轻按 BOOT，松开后再按住可开始下一次。

### 2. 三种交流模式

| 模式 | 主要用途 | 示例 |
| --- | --- | --- |
| 暖心陪伴 | 倾听情绪、回应具体困扰，按需要给建议 | “今天做什么都不顺，先听我说两句。” |
| 日常助手 | 日常问答、学习解释、帮助拆解问题 | “帮我把今天复习的事情拆小一点。” |
| 双语交流 | 按选定的中文或英文输出自然译文 | 选择 English 后，输入一句中文进行翻译 |

对话会参考同一设备最近几轮已完成交流，用户可继续追问。短期上下文与长期记忆分别管理，当前不会把全部历史永久放进每次模型请求。

### 3. 稳定的角色表达

系统提示词规定了角色的身份、表达习惯和相处边界：默认使用自然短句，先回应当前重点；复杂问题先给核心答案或一个可做的步骤，再允许追问。用户难过时回应具体经历，避免每轮使用同一套安慰词；趣味人格也会在对方难过时收起玩笑。

这些是生成引导，实际回答仍受模型与上下文影响。灵犀提供日常情绪支持，不进行心理诊断，也不承诺治疗效果；校园形象不代表学校官方服务。

### 4. 语音播放方式

语音识别、模型回复和语音合成通过所配置的云服务完成。当前支持将合成音频分块传回、边接收边播放，减少等待整段音频下载的时间。语音识别和文本生成仍会产生等待，不能描述为全程实时语音通话或零延迟交流。单次语音输出上限约20秒，较长回复可能截短；完整文字可在网页本次对话中查看。

## 三、声音、语气、人格与字体

这些设置可以分别选择，并保存给同一设备后续的对话使用。

### 1. 四种声音配置

当前提供温柔女声、磁性男声、元气少女、青年大学生四种选择。实际音色、可用权限和表现以当前云语音服务及试听结果为准；当前没有自定义声音克隆功能。

另外可以选择慢一点、自然语速、快一点，以及中文或 English 回复。

### 2. 四种语气与四套字体

| 语气 | 交流感觉 | 字体 |
| --- | --- | --- |
| 温柔安慰 | 亲切、柔和，适合倾诉与鼓励 | 柔和圆体 Resource Han Rounded |
| 平静舒缓 | 沉稳、从容，适合安静交流 | 平静宋体 Noto Serif SC |
| 活泼元气 | 轻快、有活力，适合打气与轻松聊天 | 灵动手写 LXGW WenKai |
| 清晰简洁 | 直接说重点，适合行动建议 | 清晰黑体 Noto Sans SC |

网页会结合语气改变对话区字形与色调。板上主要改变大字回复框字体，并非所有界面小字都更换。四套字体已经安装到 TF 卡，每套7029个字形，包含全部6763个 GB2312 汉字、ASCII 与常用标点。当前语气的字体会被读入内存缓存，新字体准备好后切换。

### 3. 三种相处方式

- 知心朋友：平等、亲切，以倾听和交流为主。
- 耐心学伴：把问题讲明白，帮助找到最小可行动的一步。
- 趣味搭子：适当接梗、轻松互动，按场景调整玩笑的分寸。

例如，同一个蓝蓝可以使用“磁性男声＋平静语气＋耐心学伴”；切换形象不必同时更换声音。K2 切的是语气及字体，声音需要在网页中单独选择。

## 四、五位伙伴与50段动画

| 伙伴 | 形象 | 主题 |
| --- | --- | --- |
| 蓝蓝 | 胸前带大工校标的蓝色毛绒袋鼠 | 校园陪伴 |
| 小犀 | 蓝色云朵小机器人 | 灵感与行动 |
| 奶泡 | 戴淡紫围巾的奶白毛绒小猫 | 安静倾听 |
| 团团 | 抱蓝色书本的毛绒水獭 | 耐心学习 |
| 芽芽 | 头顶双叶的薄荷绿毛绒小龙 | 元气成长 |

每位伙伴有十种动画：自然待机、认真倾听、想一想、开口回应、温柔安慰、完成庆祝、挥手欢迎、陪你专注、轻轻困倦、伸个懒腰，总计50段、2700张板端帧。

网页可主动预览“打个招呼”“一个抱抱”“陪你学习”“庆祝一下”“伸个懒腰”“晚安时刻”；真实对话过程会按倾听、思考和回应状态切换动作。还可以静态欣赏、返回当前陪伴状态；待机时会间隔出现部分小动作。

手动动作预览只展示素材。例如点击“一个抱抱”不会自动生成一段安慰语音，点击“陪你学习”也不等于启动专注计时。当前不是根据用户情绪自动识别并精准选动作。

蓝蓝十种动作的校徽素材均已按胸口中心重新定位，校徽随角色共同运动，并允许手部自然遮挡。新资源已写入 TF 卡并通过完整校验；实机逐段观感仍需现场观察。

动画使用精修3D风格二维素材，支持本地解码播放，不是实时3D模型，也没有音素级口型同步。最新修订的静音待机采样约19.2 fps，不代表所有对话状态下都固定达到该帧率。

## 五、学习搭子：待办、提醒、专注与记录

### 1. 记录和管理待办

可以新建一件事，填写计划内容、课程或分类、优先级、计划完成时间和独立的提醒时间。支持编辑、删除、标记完成、重新打开，并按全部、待完成、已完成查看。

例：计划“完成高数第二章五道练习”，分类“高等数学”，优先级设为高，分别设置完成时间和提醒时间。

也支持明确的聊天命令，例如“添加待办：完成高数第二章五道练习”。这种命令会真实写入待办；时间提醒仍需在学习页明确设置。普通聊天中让模型“安排学习”只会得到建议，不会自动保存所有建议，也不保证解析任意自然语言日程。

### 2. 到点提醒

- 网页会检查已到提醒时间、仍未完成且未确认的事项，显示提醒卡片。
- 可以点击“知道啦”确认；确认提醒与完成任务是两个操作。
- 根据用户设置和浏览器音频状态，尝试播放提示音。
- 允许浏览器系统通知后，可尝试显示系统通知。

提醒依赖网页和本机服务保持运行，当前页面约每10秒检查一次。仅填写“计划完成时间”不会自动生成提醒。关闭网页后不保证通知，也没有微信、短信或独立手机推送。

### 3. 网页专注计时

输入这次想做的事，选择时长后开始倒计时，常用选项为15、25、45、60分钟；个人偏好中还可保存默认专注时长。可以提前结束并记录，计时到期后也会在服务读取状态时归档。

专注起止时间保存在电脑数据库，刷新页面可恢复倒计时。学习记录按实际经过的整分钟保存，未满一分钟不产生一条学习记录，不会把刚开始就结束的计时记成完整25分钟。

### 4. 手动学习记录

可补记课程或内容、学习分钟数和笔记，也可删除记录。支持明确命令，例如“记录学习：高数30分钟，复习了极限”。手动补记属于用户自报数据，不是设备自动识别学习行为。

### 5. 学习统计

展示今日学习分钟数、最近七天分钟数、待完成事项、已完成事项、累计记录次数与总时长，并用七天学习足迹图查看每天的投入。统计由专注归档和手动记录计算，不是预置成绩或学习效果评估；标记任务完成本身也不会凭空增加学习分钟数。

## 六、个人偏好与口袋记忆

### 1. 可以保存的个人设置

称呼、近期学习目标、兴趣与交流偏好、默认专注时长、回复长短、鼓励方式、提醒声音等。鼓励方式有温柔、元气和务实三类；回复长短有简短、适中和展开三档。

这些偏好会进入后续对话提示词，帮助角色结合用户目标和习惯回应。当前也会提供少量待办和今日学习时长作为对话参考，但不能据此保证模型完全准确掌握所有计划或自动替用户完成事项。

### 2. 用户主动管理的长期记忆

- 保存：“记住：我喜欢先听结论，再听解释。”
- 删除：“忘记：先听结论”，或在口袋记忆列表中删除指定条目。
- 也支持明确删除全部专门的记忆条目。

当前每设备最多12条，每条最多80字，最近6条会加入短对话提示。普通闲聊不会自动变成长久记忆。删除一条记忆不代表删除聊天历史或个人设置；网页“清空”只清理本页显示的消息，服务端历史仍保留。

## 七、一分钟呼吸放松

网页提供60秒呼吸节奏：4秒吸气、6秒呼气，共6轮，使用圆球动画与文字提示引导，随时可停止。可以直接点击“一起呼吸60秒”，也可使用明确的请求，例如“带我做一次呼吸放松”，触发网页工具；普通情绪表达不会自动启动呼吸计时。

在硬件上主要通过语音给出口头引导，不能承诺板上已实现与网页相同的呼吸圆球动画。这是日常放松工具，不是医疗治疗功能。

## 八、实体设备的使用方式

设备使用正点原子 ESP32-S3 BOX 开发板，含显示屏、麦克风、扬声器、按键和 TF 卡槽。通过 UART Type-C 接电脑供电与串口调试，真实对话仍通过2.4 GHz Wi-Fi访问电脑本地服务。

| 按键 | 操作 | 功能 |
| --- | --- | --- |
| BOOT | 按住说话，松开发送 | 真实语音交流，单段最长10秒 |
| BOOT | 回复播放时轻按 | 停止当前回复播放 |
| K1 | 短按 | 切换互动动作 |
| K1 | 长按约1秒 | 开启或退出无声动画轮播 |
| K2 | 短按 | 切换语气与大字回复框字体 |
| K2 | 长按约1秒 | 开始或结束板上本地25分钟专注 |
| RST | 按下 | 复位并重新执行启动加载 |

K1/K2 在空闲时使用，录音、播放或安装资源期间暂停相应操作。BOOT 开始对话会退出无声展示。

板上 K2 专注由本地时钟运行，状态保存在 RAM，复位后不保留，也不会自动写入网页学习记录。网页专注和板上本地专注是两个独立流程。

## 九、网页与硬件如何配合

- 同一设备编号可以共用保存的形象、语气、声音和相关对话偏好；使用不同设备编号会读写不同设备的数据。
- 网页适合查看文字、管理任务与学习记录、设置偏好，以及投屏展示。
- 实物适合用按键快速说话、播放伙伴动画和进行本地专注。
- 当前不会把板上对话自动镜像成网页实时字幕；网页也不会自动同步板上K2专注记录。
- 伙伴动画、字体及板上专注可在不调用云模型时运行；真实问答与语音生成仍需网络和有效服务配置。

本地数据主要保存在电脑 SQLite；动画和字体在 TF 卡。云对话会将相关文本、语音和必要上下文发送给配置的服务，不能称为全部离线或所有内容都不离开电脑。

## 十、动画工坊与展示功能

动画工坊可预览各角色动作，对比网页高清效果与板端效果，并下载动画、字体及配套固件资源。当前硬件支持经网络把素材写入已插在板上的 TF 卡，也可以使用读卡器复制资源。

现有50段动画、四套字体已经装入用户TF卡，不需要为每次演示重新下载。启动时会重新校验较大资源，最近一次复位后全部准备约3分33秒；正式展示应提前至少5分钟上电并保持供电。

网页“现场展示”突出角色与对话区域，便于投屏，Esc 可退出；硬件K1长按则是独立的无声动作轮播。两者是不同的展示操作。

## 十一、当前完成度和介绍口径

### 可介绍为已经实现

网页文字/语音对话入口；实体按键语音链路；三种交流模式；四种声音配置、四语气、三人格和语速/语言设置；五伙伴50动作；四套TF字体；待办管理、网页提醒、网页专注归档、手动学习记录与统计；个人偏好、显式记忆与删除；网页一分钟呼吸；素材下载和TF安装。

### 已有验证证据

最终固件写入及读回校验完成；最新校徽修订动画与四字体已安装并校验；最新修订资源的短时静音播放与设备遥测通过。此前用户反馈新问题首句约3–7秒，这属于当时网络与问题下的体验，不是固定延迟保证。

### 正式展示前仍需实测

今天的真实语音、当前网络与云服务、麦克风和扬声器、K1/K2实体操作、字体可读性、校徽位置与连续动画观感。当前不能用短时静音采样证明长时间运行或所有语音状态下的流畅度。

### 团队工作的准确表述

团队基于现成ESP32-S3开发板和云模型服务，完成固件交互、屏幕界面、伙伴动画与字体资源、网页学习流程及本地服务集成。当前是软硬件原型，尚未自研量产PCB；没有任意日程自动执行、全天候离线语音、独立手机推送或完整双端状态同步。
