# 陪伴空间视觉更新与无卡动效

本次完成于 2026-10-21。入口为 http://127.0.0.1:8787/companion ，双击项目根目录 `start_companion.cmd` 可重新启动服务。

## 网页

- 使用暖白纸色、深墨蓝侧栏和钴蓝操作色，重排角色舞台、对话区、声音形象偏好和日常工具。
- 角色加入轻微呼吸、指针跟随，以及鼠标点击 / Enter / Space 的摸摸回应；遵循系统减少动态效果设置。
- 录音与播放波形读取真实音频能量；未播放时显示静止点线。浏览器使用现有真实流式接口，不使用模拟回复替代。
- 窄窗口和手机自动转为纵向布局。对话气泡、设置表单、服务配置弹窗与记忆 / 专注 / 呼吸工具保留。
- 本次沿用已有蓝蓝和小犀二维预渲染形象；这些动作不是实时 3D 骨骼动画。

## 核验

JavaScript 语法与现有流式解析回归通过：分段 UTF-8、真实音频帧先于结束帧、7 类协议 / 错误路径、呼吸延后和停止播放代际处理。55 个页面必需 ID 均存在、无重复。

通过真实浏览器检查了桌面、窄窗口、390 px 手机视口；手机无横向溢出和损坏图片。发现中等宽度下角色与说明重叠后，将纵向舞台断点调整至 700 px 并复查。测试了角色切换、摸摸回应、偏好保存和呼吸开始 / 停止。

独立测试设备 `lingxi-web-qa-20261021` 发送“你好，用一句话介绍自己。”，真实文字与语音返回，页面显示首声约 3.9 秒。服务记录首音频 3828 ms、总计 6593 ms；这是一次网页文字输入测试，不含硬件录音和 ASR，不能视为所有问题或实板的延迟保证。浏览器控制台没有警告 / 错误。实际硬件设备的偏好未用于此次保存测试。

截图保存在 `tmp/companion-premium-desktop-20261021.jpg`、`tmp/companion-premium-mobile-20261021.jpg` 和 `tmp/companion-premium-current-20261021.jpg`。

## 板端

沿用已烧录的 `firmware/box_audio_ram/releases/20261020-motion/lingxi-motion.bin`。待机呼吸、双眨眼、思考点与回复结束后的小角色动作均由现有资源和程序绘制实现，无需 TF 卡。回复文字保持 20 px 清晰大字；播放声音期间不增加动画重绘。

该发布版已通过烧录哈希、8 MB PSRAM、ES8311 和录音缓存启动检查。2026-10-21 恢复原有本机服务和临时热点后，只读检查确认板子重新连接，且服务持续收到其协议 / 设置请求并返回 200。本次未要求用户重新讲话，所以没有新的实板对话耗时测量。

## TF 扩展

建议 32 GB microSDHC / TF、Class 10 / U1、FAT32，已有 16 GB 也足够。无需另购读卡模块；若电脑无小卡槽可备 USB 读卡器。

厂家资料中的 16 / 32 GB 卡有实测记录。多套角色短动画通常只需几十至数百 MiB，容量不是流畅度的决定因素。当前版本还不读取 TF 动画素材；插卡后需继续实现帧包读取、PSRAM 预缓存和调度。建议先以角色局部 8–12 fps 为实测目标。

容量计算、厂家资料页码和后续实现边界见 [屏幕动画与 TF 卡方案](ANIMATION_STORAGE_PLAN_20261020.md)。
