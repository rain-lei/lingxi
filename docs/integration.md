## 统一的功能

`/demo` 保持图片转任务的快速演示，`/console` 继续管理任务与反馈记忆，新增 `/companion` 陪伴/学习入口和 `/animations.html` 动画工坊。

- 原始文本、图片与语音接口继续工作；新增硬件 PCM 输入、LXI1 完整音频和 LXS1 流式音频。
- `tasks` 为唯一有效任务表。学习页的“待办”映射为 confirmed，AI 提取的任务仍为 pending，确认后才会到期提醒。编辑、完成、撤销提醒、删除在两边同步。
- 原 `companion_learning_tasks` 仅保留为迁移来源。启动事务把旧行导入 tasks，保存旧/新 ID 映射，以迁移标记防止重复导入和删除后复活。两个表的 ID 冲突不会覆盖任务。
- 生成新任务不会再自动删除历史任务。列表返回数量仍有上限。
- 陪伴与硬件对话读取原有反馈偏好，任务时间计算也使用这些偏好；显式“记住”的事实可供原控制台的模型对话使用。两类记忆保留各自可删除的记录，避免把事实误变成行为规则。
- 翻译模式不生成任务；明确的“添加待办”命令只创建一次。
- 专注计时、学习记录、偏好、动画与声音配置按设备 ID 保存。

## 身份与数据

三个业务页面共用已有的 `lingxi-browser-device-id`，不改变原浏览器历史。首次访问不会选中上游硬编码的实体设备。

实体设备在陪伴页“我的偏好”中输入编号和配对码，验证成功后才切换。选择和配对码仅保存在当前标签页的 sessionStorage，同一标签页进入控制台即可管理同一设备；使用“返回浏览器体验”可退出。编号链接只预填表单，不会自动取得设备访问权。

对外部署设置 `LINGXI_DEVICE_TOKEN`。非浏览器 ID 的原控制台读写接口、陪伴接口与硬件音频接口使用同一配对码验证；本机同源维护保留本地访问便利。`web-` 为匿名浏览器保留前缀，不用于实体设备编号。

当前仍是黑客松原型：匿名浏览器使用不可枚举的随机 ID，没有账号登录；知道完整匿名 ID 就能访问该匿名会话。设备配对码是服务级共享码，没有逐设备授权体系。面向长期多用户服务还需要账号、每设备凭证、绑定/解绑和独立用量配额。

统一启动数据库为 `data/lingxi_demo.db`（Docker 为 `/app/data/lingxi.db`）。本次不自动把另一台电脑的数据库文件混入现有数据库。如果要迁移其历史，先将数据库副本作为候选环境输入；不要直接覆盖现有数据文件。启动会自动升级同一文件内的旧表。

## 二进制资源与构建

上游 637 个 Git LFS 指针已转成 `assets.lock.json`，记录原提交、路径、SHA-256、大小和运行范围。图片/字体/固件不是指针文本；脚本从固定提交获取真实文件，校验后原子替换。相同摘要仅下载一次，运行时无需联系 GitHub。

```sh
python tools/fetch_assets.py --scope runtime
python tools/fetch_assets.py --check
python server.py --host 127.0.0.1 --port 8787
```

默认准备 162 个线上所需资源（约 290 MiB 唯一内容），包含当前角色动画、字体、TF 动画包与下载固件。历史素材、旧动画版本和固件构建素材可用 `--scope all` 获取（约 2 GiB 唯一内容）。依赖上游资源可用性，建议发布时另存经过校验的资源镜像。下载中断可以重跑，不会接受截断文件或错误摘要。

`start_companion.cmd` 使用同一下载脚本和默认数据库。Dockerfile 同时复制全部 Python 模块和 prompts，并在构建阶段补齐缺少的运行资源；不能省略这一步直接部署 `git archive` 中的文件。离线构建可先把校验后的运行资源放回 public 对应路径。

## 升级与回滚

1. 用 SQLite backup API 备份当前数据库（运行中直接复制 `.db` 可能遗漏 WAL 数据），保存当前镜像标签和环境配置。
2. 构建候选镜像：`docker build -t lingxi:integrated .`。
3. 使用备份的测试副本/独立 Docker volume，在另一 localhost 端口启动；检查四个页面、旧任务、任务互通、配对、声音和图片。
4. 验收后替换服务容器，继续挂载原 data 卷并传入原密钥配置。Nginx 保留 `proxy_buffering off`，以支持 NDJSON 和 LXS1。
5. 回滚必须同时恢复旧镜像和升级前的数据库备份；保留升级后数据库副本以免丢失新增记录。

本次只完成代码整合与候选环境验证，不替换线上服务。模型/语音测试使用本地可控 Provider，没有消耗真实 API 额度。硬件协议软件测试不等于实板验收：麦克风、扬声器、按键、TF 卡和真实网络需另行联调。
