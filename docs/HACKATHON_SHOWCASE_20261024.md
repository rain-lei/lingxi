### 人员分工

讲解者负责讲故事、举板子、按 BOOT 说话；操作员负责电脑页面、待办表单、计时和故障切换。只有一个人时，提前排练页面顺序，保留一次语音和一次待办保存。

### 上台前必须满足

电脑和板子保持联网及供电；TF 动画已加载；今天实际按 BOOT 成功对话一次；K1 与 K2 实体操作已彩排；备用实机视频已录好并保存在电脑。

## 硬件怎么接与网页怎么开

连接：电脑 USB口 → 数据线 → 板子丝印 UART 的 Type-C口。网络：板子 → 电脑2.4 GHz热点 → 本地服务 → 已配置的云端语音服务。

1  电脑先接电、联网并连接投影。演示期间保持唤醒和开启状态。沿用排练成功的网络，手机移动数据作为网络备用。

2  在 D:\比赛项目\lingxi-main 中双击 start_companion.cmd，保留启动窗口。脚本会尝试恢复已配置的 LingXi-Link 热点，并沿用原展示数据库。确认 Windows 移动热点为 2.4 GHz。

3  TF 卡保持插在板子卡槽内。用数据线连接电脑与板上标有 UART 的 Type-C口；麦克风、扬声器已在板上，不用另接杜邦线。上电时松开所有按键。

4  至少提前 5 分钟上电。上次复位后完整验卡与字体准备约 3 分 33 秒；等动画稳定、服务连接后再演示。上台后保持供电，避免重新进入验卡等待。

5  网页使用下面固定入口，确保与板子使用同一设备编号。页面能打开后，还要按 BOOT 做一次真实语音测试。

http://127.0.0.1:8787/companion?device_id=lingxi-30eda01e922c#home

| 按键 | 短按或正常操作 | 长按约一秒 |
| --- | --- | --- |
| K1 | 点按并松开，切换互动动作 | 进入或退出无声动作轮播 |
| K2 | 切换语气与大字回复框字体 | 开始或结束本地25分钟专注 |
| BOOT | 按住说话，讲完松开；单段最长10秒 | 按住期间录音；上电时松开 |
| BOOT / 播放时 | 轻按停止当前回复，再松开 | 停止后重新按住可开始下一次 |
| RST | 复位，会重新验卡 | 正式展示不安排此操作 |

地址不要混用：127.0.0.1 是电脑自己的网页；192.168.4.1 是板子配网页；板子访问的服务地址是电脑局域网地址，现有热点模式通常为 http://192.168.137.1:8787，以当天实际网络为准。USB 不代替 Wi-Fi。

## 五分钟讲解词与操作提示

### 0:00–0:30 开场

讲解：“大家好，我们的作品是灵犀，一个面向大学生的随身学习与陪伴伙伴。遇到上台紧张、学习分心或者事情易忘时，我们希望它能及时回应，也陪你把下一步做起来。”

操作：网页先开“现场展示”，保持蓝蓝大画面；讲解者举起实物。

### 0:30–1:00 让伙伴先被看见

讲解：“这是我们的校园伙伴蓝蓝，胸前保留了大工校徽。待机、倾听、专注和安慰都有对应的小动作，动作素材也已经装进这张 TF 卡。”

操作：电脑点击“打个招呼”或“一个抱抱”；板子空闲时短按 K1。只演示一两段，不遍历全部动作。

### 1:00–2:00 做一次真实语音对话

按住 BOOT，说完松开：
“我要上台了，有点紧张。用两句话，先安慰我，再给一个小建议。”

讲解：“现在声音由实物采集，经过语音识别、模型生成和语音合成，再回到板子播放。我们希望它先接住情绪，再给一个足够小、能行动的建议。”

操作：靠近板子麦克风，正常语速，控制在10秒内。松开后等待首句；15秒仍无声就按备用流程切换，避免重复提交。网页不会自动弹出这次板子对话的同步字幕。

### 2:00–2:50 把陪伴落实成行动

讲解：“得到鼓励之后，更重要的是把想做的事留下来。我们可以记下展示后的复盘，设置准确的提醒，再开始一段专注。”

操作：Esc 退出现场展示 →“记下一件事”→ 填“展示结束后整理评委反馈”，分类填“黑客松”；提醒日期选今天，时间选当前分钟加两分钟 →“保存这件事”。尽量2:30前保存，再填专注内容“黑客松现场展示”，点“开始专注”。

### 2:50–3:45 展示个人化设置

讲解：“语气、字体、声线和伙伴形象可以分别选择。温柔圆体、平静宋体、元气手写和简洁黑体，对应不同的交流感受。个人称呼、兴趣和学习目标也可以保存。”

操作：打开“我的偏好”，切一次语气并点“保存偏好”，再回主页看欢迎气泡或对话区的字形变化。声音选择框展示选项即可；保留蓝蓝，不追加第二个云端问题。

### 3:45–5:00 看见结果并收束

操作：回主页看提醒，出现后点“知道啦”。网页专注实际经过至少一分钟，再点“结束并记录”，展示新增记录和统计；随后回到“现场展示”。

收尾：“灵犀把校园伙伴的陪伴体验、随手可用的硬件入口，以及计划和学习记录连在一起。我们已完成这套软硬件原型，下一步会继续优化启动等待和对话延迟，并通过真实使用验证陪伴是否能转化成持续行动。”

## 赛前彩排与现场备用方案

### 按这个顺序做赛前准备

[ ] 提前45分钟：电脑接电和投影，确认外网可用。准备原数据线、备用数据线、手机和本地视频播放器。

[ ] 提前30分钟：启动服务和热点，板子上电并等待验卡。实际测试一次 BOOT 对话；再试 K1 短按与长按、K2 短按与长按。

[ ] 提前20分钟：用一次真实彩排专注留下初始学习记录；测试一条未来提醒。录一段30–45秒实机备用视频，包含动作和一次真实语音回复，保存到电脑并试播。

[ ] 提前10分钟：设置蓝蓝、温柔语气及已试听的声音。关闭无关窗口和可能弹出的私人通知；配网页和密钥设置留在赛前完成。

[ ] 提前5分钟：保持板子与电脑供电。打开主陪伴页、动画工坊和备用视频；预览一次招呼与专注动作，回到开场大画面。

### 故障时的切换规则

| 现场情况 | 操作员立即做什么 |
| --- | --- |
| 语音15秒仍无首声 | 讲解者继续介绍链路；切本地实机视频，并说明是赛前录制。随后继续网页计划和提醒，不反复发起语音。 |
| 板子未连电脑服务 | 电脑网页继续演示；赛后再查热点和局域网地址。若外网也不通，改用本地动画、表单与视频。 |
| 显示内置画面或正在验卡 | 保留供电，先展示网页；等待加载完成。重新拔插会重新开始启动流程。 |
| K1或K2暂时不响应 | 先确认已结束录音和播放、板子处于空闲。界面报错时转网页备用，不现场刷机。 |
| 提醒还没弹出 | 先看提醒时间是否填对，留约10秒轮询余量；时间紧就展示已保存的条目和提醒时间。 |
| 专注结束没有新记录 | 检查是否真实经过至少一分钟。不足一分钟时，展示已保存计划和此前真实彩排记录。 |

### 时间快超了就删这两项

保留一次真实对话、一次待办保存和收尾。删掉换声音的额外试听与专注归档等待；不要为了补环节耽误最后的项目总结。备用视频必须说明为预录实机验证。

临时压缩到3分钟：20秒开场，50秒硬件对话，60秒保存待办并展示已有记录，50秒展示个性设置与总结。提醒与专注归档改作答辩备选。

正式展示不安排刷固件、重新下载约50 MiB动画、设置 API Key、首次申请麦克风权限或临时换网络。这些都在彩排中完成。

| 仍需现场验收 | 最新实体按键、人眼观感和当前网络下的真实语音。以今天彩排通过的项目进入主流程。 |

### 与普通聊天工具有什么区别

“我们把校园伙伴形象、实体按键入口和学习行动放在同一套产品流程里。对话之后能留下计划、提醒和真实学习记录，这是这次原型重点验证的体验。”

### 硬件和模型哪些是团队自己做的

“我们使用正点原子 ESP32-S3 BOX 开发板和现有模型服务。团队完成固件交互、屏幕界面、动作与字体资源、网页学习流程及本地服务集成。当前是软硬件原型，尚未自研量产 PCB。”

### 离线能用吗 数据在哪里

“动画素材和字体在 TF 卡，板上专注计时在本机运行；网页数据存于电脑 SQLite。真实语音对话需要联网调用配置的云服务。密钥保存在本机，语音会发送给所配置的语音服务。”

### 延迟和动画流畅度怎样

“最新资源的静音待机采样约19.2 fps；此前用户反馈新问题首句约3–7秒，但不是所有网络和问题的保证。我们会用现场真实结果回答延迟，目前仍在优化启动加载和云端链路。”

### 需要主动说明的产品边界

网页与板子共用设备偏好，当前不自动镜像硬件对话字幕。板上 K2 专注不会自动写网页学习记录。页面提醒依赖网页和服务运行；动作是精修二维纹理动画，未做音素级口型同步。

问答备用：显式“记住：……”与删除、60秒呼吸、声音与人格选择、五伙伴十动作、个人目标。只有评委追问时再打开，避免主流程变成菜单巡游。
