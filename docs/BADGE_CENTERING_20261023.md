# 蓝蓝胸前校标定位修订（2026-10-23）

修订标识：`badge-center-r2`。本次修复蓝蓝十种动作中校标相对胸口偏移的问题，更新网页高清素材和 TF 动画包。使用项目中已有的大连理工大学官方校标图层，未重新生成或改画校标。

## 按胸口定位

校标的定位基准是**各姿态乳白胸腹区域的中轴与胸口位置**，不是整张 512 × 512 图的中心，也不是包含耳朵和尾巴的全身外框中心。角色转头、侧身或抬手时，胸口在图中的位置不同，因此每张姿态分别记录锚点及校标尺寸；不会为了手遮挡后的图案像素左右对称而挪离胸口。

定位参数保存在 `tools/build_tf_animation_v3.py`，并写入各蓝蓝 clip 的构建记录 `source.badge_alignment`。源格坐标先经过扩展窗口、主体提取、裁切、统一缩放和基线对齐，再转换到规范纹理坐标。

| 源纹理编号 | 源格胸口锚点 `(x, y)` | 对应动作 |
| --- | --- | --- |
| 0 | `(276, 370)` | 自然待机 |
| 1 | `(245, 370)` | 保留的基础源姿态，本版动作映射未使用 |
| 2 | `(233, 370)` | 认真倾听 |
| 3 | `(273, 365)` | 想一想 |
| 4 | `(244, 350)` | 开口回应、完成庆祝 |
| 5 | `(240, 307)` | 温柔安慰 |

| 9 | `(268, 390)` | 伸个懒腰 |

源纹理编号不等于动作状态编号。例如，回应与庆祝共用基础姿态 4，再分别应用各自的局部动作节奏。

## 跟随动作与自然遮挡

渲染器 `tools/tf_animation_renderer_v3.c` 在源纹理采样时合成官方校标。角色与校标随后共用同一套采样坐标变形，包含躯干呼吸、整体移动和相应局部动作，避免把校标作为固定屏幕图层独立漂移。

- 蓝色毛绒手爪位于校标前方，允许动作产生自然遮挡。
- 专注姿态的书本位于腿部，保留胸口空间。
- 合成保持原主体 alpha，不因校标扩大角色轮廓或绘入透明背景。
- 网页与板端分别声明校标已合成，网页无需再叠加备用 SVG 校标。

这仍是精修 3D 风格的二维纹理动画；本次定位修订没有把资源改成实时 3D 模型。

## 重绘范围与缓存

蓝蓝十段动作全部重绘。前六段使用原有 V2 高分辨率源纹理重新合成与采样，**不再复用 V2 已合成 APNG**；后四段仍使用 `firmware/box_audio_ram/assets/tf-v3/kangaroo-extra-source.png` 的欢迎、专注、困倦与伸展源姿态。

十段动作的网页海报、透明 APNG 与板端 GIF 都采用包含修订号的文件名，例如：

```text

/animations/v3/previews/kangaroo-idle-badge-center-r2-motion.png
/animations/v3/previews/kangaroo-idle-badge-center-r2.gif
```

目录 URL 已指向新文件，胸口锚点记录参与构建 fingerprint，避免浏览器旧 URL 缓存与生成缓存继续提供修订前的图像。其他四位伙伴的源图与动作流程保持原样。
