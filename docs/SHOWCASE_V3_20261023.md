## 网页体验

- 更大的角色舞台、清晰文字层级、暖白与深蓝配色，集中展示对话、今天待办和专注入口。
- 可手动预览打招呼、安慰、学习、庆祝、伸懒腰和困倦动作；倾听、思考、回应跟随实际对话状态。
- 支持静态欣赏和返回当前陪伴状态。手动预览不伪造语音回应。
- 学习页可编辑待办、提醒、学习记录与专注归档；个人偏好可设置称呼、兴趣、目标、回答长短及鼓励方式。
- 选择语气会改变真实回复设置及对应字体、色调；声音与人物形象可分别选择。
- 网页提醒需要本机服务及页面运行；系统通知仍需浏览器授权。

网页专注归档与下面的**板上本地专注计时**是两个独立流程。板上计时不会自动创建网页记录，也不会自动上传云端学习记录。

## 板上按键

在板子空闲、未安装素材、未录音/播放时使用 K1、K2。长按阈值为 **800 ms**；松开长按后不会额外触发一次短按。

| 按键 | 操作 | 功能 |
| --- | --- | --- |
| K1 | 短按并松开 | 依次播放当前伙伴的互动动作 |
| K1 | 长按 ≥800 ms | 开启/关闭无声展示轮播 |
| K2 | 短按并松开 | 依次切换 `warm → calm → cheerful → direct → warm` |
| K2 | 长按 ≥800 ms | 开始/结束本地 25 分钟专注计时 |
| BOOT | 按住说话，松开 | 录音并发起真实语音对话，最长 10 秒 |
| BOOT | 回应播放时轻按 | 中止当前回应播放 |
| RST | 按下 | 复位，保持原有用途 |

BOOT 优先于无声展示，开始对话会退出展示轮播。录音和播放期间不接受 K1/K2 互动，素材安装期间暂缓新对话。

K2 选择语气后，固件向后端异步保存设置；紧接着发起的语音请求还会发送允许列表内的 `X-Lingxi-Tone`，使本次对话及时采用新语气，不覆盖声音、人物或人格偏好。

### 板上专注的边界

- 仅由板子本地时钟计时，结束时显示提示并尝试播放庆祝动作。
- 不请求大模型、不自动写网页/云端学习记录、不保证手机通知。
- 当前计时状态保存在 RAM，复位后重新开始。
- 如需保留学习统计，可在网页学习页主动记录。

## 50 段动画

五位伙伴：蓝蓝、小犀、奶泡、团团、芽芽。每位十段：

| 动作 ID | 动作 | 播放方式 |
| --- | --- | --- |
| `idle` | 自然待机 | 循环 |
| `listening` | 认真倾听 | 循环 |
| `thinking` | 想一想 | 循环 |
| `speaking` | 开口回应 | 循环 |
| `comfort` | 温柔安慰 | 循环 |
| `celebrate` | 完成庆祝 | 单次 |
| `greeting` | 挥手欢迎 | 单次 |
| `focus` | 陪你专注 | 循环 |
| `sleepy` | 轻轻困倦 | 循环 |
| `stretch` | 伸个懒腰 | 单次 |

蓝蓝每段动画均保留胸前官方校标。原有高清素材与新增姿态结合局部动作，避免整幅姿态交叉淡化造成双眼、双鼻等重影。网页使用 512 × 512 透明 APNG；板端为 128 × 128 RGB565LE + alpha8。

板端共 **2700 帧**，50 ms 素材节拍，对应 **20 fps 目标**。这不是已测得的实机帧率。固件按截止时间调度，迟到时跳帧；只重画伙伴区域并复用缓存，减少整屏刷新。

说话动作属于预置表情，**不是音素级口型同步**。待机偶尔插入招呼或伸懒腰，K1 可主动触发更多动作。

## 四语气与四套字体

| tone 枚举 | 中文语气 | 字体 |
| --- | --- | --- |
| `warm` | 温柔安慰 | 柔和圆体 / Resource Han Rounded |
| `calm` | 平静沉稳 | 平静宋体 / Noto Serif SC |
| `cheerful` | 活泼元气 | 灵动手写 / LXGW WenKai |
| `direct` | 简洁利落 | 清晰黑体 / Noto Sans SC |

每套 **7029 字形**，覆盖全部 6763 个 GB2312 汉字、ASCII 与常用标点；使用原生 20 px、2 位抗锯齿。四套采用一致的排版前进宽度，异步换字体时保持分页稳定。

全部来源采用 SIL OFL 1.1，随包保留作者版权、来源及许可证。详情见 [TF 语气字体说明](TF_TONE_FONTS_20261023.md)。

卡上四套字体合计约 3.79 MiB。只在空闲时将当前语气的一套加载到 PSRAM（约 0.95 MiB），绘字不逐字读卡；交换时保留旧缓存，校验新字体后才切换。无卡时仍有嵌入的完整 Noto 20 px 后备字体。

## 格式与兼容性

| 资源 | 格式 | 卡上路径 |
| --- | --- | --- |
| V3 动画 | **LXAF version 2**，逐帧无损 RLE3，包体 SHA-256、clip CRC32 | `/lingxi/animations-v1.lxaf` |
| 语气字体 | **LXFF version 1**，字形索引 + 2 位 alpha，包体 SHA-256、字体 CRC32 | `/lingxi/fonts-v1.lxff` |

动画文件名中的 `v1` 是固定设备路径，**不表示动画仍采用旧格式**。新固件支持 LXAF 1 和 2；旧固件不能读取 V3 压缩动画。

设备下载地址保留 `/animations/v1/lingxi-animations-v1.lxaf`，由发布脚本将校验后的 V3 数据原子替换到该地址。V3 的独立原始文件仍保留在 `/animations/v3/`，此前 V2 实际素材也保留。

下载先写 `.part`、核对长度/SHA/CRC，再替换并保留 `.previous`。不格式化卡。字体与动画可分别安装，不必为更换字体重传动画。

### 安装方式

1. 更新配套固件，使用 FAT32 TF 卡。
2. 电脑运行本地服务，板子连接能访问电脑的 2.4 GHz Wi-Fi；硬件的服务地址填电脑局域网地址，不能填手机或板子自己的 `127.0.0.1`。
3. 手机连接板子热点（通常为 `LingXi-922C`，以屏幕显示为准），打开 `http://192.168.4.1/`。
4. 在配置页分别选择“从电脑安装动画”和“安装语气字体”，等待各自校验结果。
5. 也可用读卡器复制：动画包内的 `lingxi` 文件夹放到卡根目录；字体包中的 `lingxi-fonts-v1.lxff` 复制并命名为卡上的 `lingxi/fonts-v1.lxff`。

本轮已通过板子自身下载并校验两种资源，合计用时 **533.2 秒（约 8 分 53 秒）**，不是要求用户再次安装。动画状态为 LXAF v2 / 50 段 / `ready`，字体为 `installed=true`、`cached=true`、`ready`，两者错误字段均为空。这个耗时包含传输、校验与缓存准备，不能作为所有网络和 TF 卡的固定安装时长。

## 闪屏/启动异常的修正

本轮曾出现启动反复复位。静态审计发现，绘制函数将包含 2048 字节回复的模型复制到栈上，编译后启动绘制链至少 4176 字节，超过当时 3584 字节主任务栈。

现已改用静态绘制模型缓冲，并设置 **8192 字节主任务栈和强栈保护**，增加剩余栈空间诊断。最终固件写入后，35 秒启动观察仅出现一次启动消息、到达应用就绪、未记录错误；后续 41.719 秒静音遥测窗口没有计数器回退或 HTTP 失败，主栈剩余量最低为 **5360 字节**。这些结果支持本轮启动异常已修复，但不代替断电冷启动、长时间运行或用户对屏幕闪烁的观察。

**测量方式与范围：** 帧率取板端实际显示帧计数的增量除以电脑单调时钟经过时间。独立待机参考窗口采样的单次绘制耗时约 24.7–25.9 ms，渲染最高采样值约 17.0 ms，LCD 传输最高采样值约 8.95 ms；只代表该窗口采样值，不是全生命周期分位数或所有帧的最大耗时。其间没有缓存缺失或新增资源加载，不能覆盖冷切换时的首次读卡等待。

六种动作测试为 **静音、远程 UI 预览**，不是模拟一次完整真实对话。名为 `speaking` 的动作预览未打开麦克风或播放 I2S 音频；名为 `focus` 的动画也不表示已经启动 K2 的专注计时。短动作测试排除有意停留的最终姿态，其短窗口帧率存在边界误差，不能把个别短窗口数值当作长期保证。

四字体切换由软件设置触发并核对设备缓存状态，未操作实体 K2；加载新字体的观测耗时约 13.6–16.2 秒（已有 warm 缓存约 0.2 秒），其中包含后端偏好最长 15 秒的轮询等待，并非单纯读卡耗时，也不代表实体 K2 的切换延迟。切换时继续保留旧字体，不能描述为四套都已同时驻留或立即换字。测试后已恢复原来的 `warm`。本轮没有现场截图，所以设备状态确认不等于已确认实际文字观感。

**当前启动限制：** 每次重新启动都会在后台完整校验约 50 MiB 的动画和字体。本次复位后全部资源就绪耗时约 **3 分 33 秒**，期间保留内置画面；此时还没有进入已测得的 TF 动画播放状态。现场展示建议提前约 4 分钟开机，等待卡上动画、字体均就绪。这里测的是复位重新启动，未代替现场断电上电与人眼检查。
