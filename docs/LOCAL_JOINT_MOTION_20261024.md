# 动画局部关节修订

修订号：`local-joints-r3`。日期：2026年10月24日。

## 本次问题

用户观察到打招呼等动作更像整个角色或空间在晃动，手臂动作不明确。检查发现，原渲染器的通用手臂位置没有对应各姿态的实际肩关节，且身体形变和整体移动比手部运动更显著；网页还叠加了鼠标视差、静态图整体摇摆和装饰漂浮。

## 修改内容

- 按角色与姿态分别定位关节和手臂区域，使用连续局部关节逆解表达动作，避免手臂抽离后露出缺少的底层纹理。
- 去除整体平移、整体缩放和胸口形变，保留局部表情与关节动作。
- 挥手回到原始姿态后结束；伸展由双臂表达，避免牵动脸部和耳缘。
- 保留蓝蓝 `badge-center-r2` 的胸口锚点和自然遮挡。
- 五位伙伴的50段素材统一经过当前渲染器重建，停止复用其他角色的旧V2动画。
- 新APNG、海报和板端GIF使用含 `local-joints-r3` 的文件名，避免旧素材缓存。
- 网页陪伴空间与动画工坊移除整图视差、假挥手和背景装饰漂浮，保留固定居中、真实素材动画和暂停操作。
