# 蓝蓝的口袋：角色、互动与流式语音

## 本次可用功能

- **稳定的角色**：`prompts/lanlan_system.md` 是每轮实际读取的角色提示词，蓝蓝/小犀、相处方式、语气、语言、称呼和最近四轮对话一起参与生成。自然接话、适度幽默、具体回应困扰，不机械夸奖或虚构真人经历。
- **口袋记忆**：说“记住：我喜欢散步”，本机 SQLite 保存明确内容；最多 12 条、每条 80 字。同一个设备编号可在网页查看和删除，语音支持“忘记关于散步的记忆”。普通聊天不自动写入该长期记忆表。删除长期记忆不等于清除聊天历史或称呼设置。
- **一起专注**：说“陪我专注25分钟”或点击按钮，保存真实起止时间，网页显示倒计时，刷新或服务重启可恢复。支持 1–60 分钟和“结束专注”。当前没有到点后台响铃、推送或硬件闹钟。
- **一分钟呼吸**：网页点击即开始，无需模型或网络；4 秒吸气、6 秒呼气，共六轮，可随时停止。语音说“带我呼吸一分钟”也可让网页在口头引导后开始动画；硬件当前只有口头引导。
- **路演搭子**：快捷入口要求模型扮演评委，每次问一个问题，结合回答继续反馈。它属于角色驱动的多轮对话，不是专业评分系统。
- 保留四种音色、语速、语气、中英翻译、两个人物形象。

## 如何体验

1. 双击根目录 `start_companion.cmd`，打开 <http://127.0.0.1:8787/companion>，已有密钥继续使用。
2. 按住板子的 BOOT 说话，松开发送；网页可用文字或麦克风测试。
3. 依次试：“你是谁？”→“记住：我的作品叫蓝口袋”→“我的作品叫什么？”→“陪我专注25分钟”。
4. 点网页“一起呼吸60秒”，再点“路演搭子”，说明自己的项目，展示连续追问。
5. 网页与板子使用同一个设备编号时，共享记忆和偏好。实际设备 `lingxi-30eda01e922c`。

## 为什么此前一轮超过 15 秒

真实服务日志中，一轮识别 1250 ms、对话生成 5735 ms、整段 TTS 8296 ms，总计 15297 ms。原实现必须完成全部语音合成、下载，板子才播放；仅修改提示词无法消除这一串行等待。

新客户端使用 LXS1：生成回复文字后，TTS 请求明确启用 `stream_format=audio`，原生 PCM 分块发给网页/板子。网页排队播放，固件使用 64 KiB 环形队列和约 120 ms 预缓冲，主任务独占 I2S 和 LCD。旧 LXI1 接口继续兼容。

固件另将可选设置轮询由 5 秒连接 / 8 秒总预算缩短为 750 ms 连接 / 响应头、1.5 秒总预算，避免设置查询长期挡住新语音请求。

## 协议及异常恢复

请求 `Accept: application/vnd.lingxi.voice-stream`；回复 MIME 相同。HTTP 连接关闭定界，无 Content-Length，不采用 HTTP chunked 编码。

正文为 `LXS1`，随后每帧 1 字节 ASCII 类型、4 字节小端长度、负载：

- `J`：初始 JSON，含回复文字、转写、设置及 16kHz / PCM16LE / 单声道格式。
- `A`：最多 4096 字节偶数长度的真实 PCM，总计最多 640000 字节。
- `D`：最终 JSON，音频字节数必须等于实际接收量，附阶段耗时。
- `E`：终止错误 JSON。断流、长度错误或 E 不算完整成功；清空声音队列。

固件收到 LXS1 后可按 BOOT 中止当前播放和接收。尚未收到响应头的识别/生成等待阶段暂不能用 BOOT 取消，仍受请求超时约束。设备可以在可恢复对话错误后再次按住 BOOT 重试。
